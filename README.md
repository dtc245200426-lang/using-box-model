# Thực hành sử dụng box model

Bài hoàn chỉnh theo bước 4 của hướng dẫn CodeGym.

Mở `index.html` bằng trình duyệt để xem kết quả.

- Hộp ngoài: chiều rộng nội dung 800px, padding 10px, viền nét liền 10px, căn giữa bằng `margin: 0 auto`.
- Màu viền theo chiều kim đồng hồ: chartreuse (trên), aqua (phải), blue (dưới), blueviolet (trái).
- Nền hộp màu trắng.
- Ba đoạn văn: viền chấm darkred 3px, padding 10px.
- Lề dưới của ba đoạn lần lượt là 20px, 40px, 60px.

Với box model mặc định `content-box`, chiều rộng tổng của hộp ngoài là 840px (800 + 20 padding + 20 border).
